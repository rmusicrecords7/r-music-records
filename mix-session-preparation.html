How to Prepare a Session for Mixing: An Artist’s Checklist

Prepare WAV files, matching start times, clear track names, headroom, tempo, key and references.

A clean handoff saves time before the first mix decision is made. A session that opens correctly, uses consistent file starts and has clear track names lets the engineer focus on sound rather than reconstructing the project.

Export audio consistently

Use WAV files at the session's native sample rate and an agreed bit depth. Export every stem from the same start point, including silence before the first note, so the files line up when imported. Do not normalize each track separately. Leave sensible headroom and avoid clipping on individual channels or the master bus.

Practical export baseline: use 24-bit WAV and the session’s native sample rate (commonly 44.1 or 48 kHz). Export every track from the same project start, keep all files the same length, and make sure peaks do not reach 0 dBFS. Remove a loud master-bus limiter unless it is an intentional part of the approved sound. If a creative effect defines a sound, provide both processed and dry versions where practical.

Organize and label tracks

Use descriptive names such as Lead Vocal, Vocal Double L, Kick, Snare Top, Bass DI and Synth Pad. Keep stereo files stereo and mono files mono. Remove unused takes and muted tracks unless they contain useful alternatives. If there are many tracks, group them logically and provide a simple track list.

Include musical information

  • Tempo and time signature, including tempo changes.
  • Key, if known, and any tuning reference.
  • A rough mix that shows the intended balance and effects.
  • Two or three reference tracks with notes on what you like about them.
  • Lyrics, section markers and important arrangement notes.

What about plugins and effects?

Print creative effects that are part of the sound, but also provide dry versions when practical. Tell the engineer which reverbs, delays or distortion are essential. Do not assume that a plugin preset will transfer exactly between systems. If a virtual instrument is important, export its audio as well as keeping the MIDI and instrument information.

Takeaway: consistent exports, clear labels, headroom and useful references make remote mixing faster and reduce avoidable revisions.
